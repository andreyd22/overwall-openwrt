# Установка Overwall VPN на OpenWrt

Версия 0.1.1 — открытая бета. Полная актуальная инструкция:
https://overwall.online/download#openwrt

Минимум: OpenWrt 25.12.x/24.10.x, LuCI, 256 МБ RAM и 50 МБ свободного
постоянного хранилища. Рекомендуется 512 МБ RAM. Сделайте резервную копию
настроек в LuCI и подключитесь к роутеру кабелем.

По SSH от root выполните:

```sh
uclient-fetch -O /tmp/overwall-install.sh https://overwall.online/downloads/openwrt/0.1.1/install.sh &&
sh /tmp/overwall-install.sh
```

Установщик добавляет открытый ключ доверия и подписанный репозиторий Overwall,
затем устанавливает `luci-app-overwall` вместе с клиентом и всеми зависимостями
из официальных репозиториев архитектуры/прошивки. Не отключайте проверку подписей
и TLS, не используйте принудительную установку несовместимых модулей ядра.
После первой установки перезагрузите роутер и откройте «Сервисы → Overwall VPN».

В «Настройки» выберите LAN или существующую гостевую сеть и автозапуск.
Нажмите «Войти в Overwall», откройте QR/ссылку на телефоне, войдите в свой
аккаунт на overwall.online, сверьте код и подтвердите подключение. После входа
выберите карточку VLESS или свободный профиль WireGuard. Занятые другим
устройством WG-профили необходимо сначала освободить на том устройстве.

«＋ Своё подключение» добавляет независимую HTTP(S)-подписку, VLESS/Base64/JSON
или WireGuard-конфигурацию (текст/файл). Вход в Overwall не нужен. Секреты
хранятся на роутере. Подписка должна быть конечной публичной ссылкой без
перенаправления. WireGuard: один Peer, IPv4, AllowedIPs=0.0.0.0/0; исполняемые
хуки отклоняются. AmneziaWG не входит в выпуск.

При обрыве VPN прямой выход выбранной сети и её IPv6 блокируются. Окончание
трафика определяется подтверждённым API-ответом, а не отсутствием активности.
WireGuard-доступ проверяется отдельно от VLESS. Свои источники независимы от
квоты Overwall. Captive-окно зависит от ОС; можно открыть обычный HTTP-сайт.
HTTPS не подменяется. В бете внешние банковские страницы ещё не прошли полную
проверку из закрытой сети; для оплаты используйте мобильный интернет телефона.

Для обычного интернета нажмите «Отключить VPN» (также выключает автозапуск).
Восстановление по SSH: `overwall disconnect`. Панель роутера остаётся доступной.
Перед удалением отключите VPN, затем удалите оба пакета менеджером пакетов.
Обновляйте оба пакета совместно через репозиторий Overwall; не выполняйте
массовое обновление всех системных пакетов OpenWrt.

Начиная с 0.1.1 «Отключить VPN» также освобождает слот WireGuard, а переключение
сначала освобождает предыдущий. Если API временно недоступен, VPN уже отключён,
но освобождение ожидает связи: роутер повторит запрос автоматически. Другой
слот до подтверждения освобождения не занимается. Сон/временный обрыв не
освобождают назначение. Сохранённый сторонний .conf остаётся переносимым.
